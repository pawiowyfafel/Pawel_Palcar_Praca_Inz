# Pawel_Palcar_Praca_Inz

Praca inżynierska: weryfikacja autentyczności zdjęć zgłoszeń szlakowych na urządzeniu mobilnym
(autentyczne zdjęcie szlaku vs miasto / mem / AI / manipulacja).

- `src/collect/` – pobieranie danych z poszczególnych źródeł
- `src/` – filtr CLIP, normalizacja, przegląd, deduplikacja, podział, statystyki
- `docs/dane/01_klasa_pozytywna.md` – skąd są dane klasy pozytywnej i jak je zbieramy
- `data/` – dane (poza git, oprócz `data/manifests/`)
